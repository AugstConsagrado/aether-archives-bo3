# Aviso de projeto

**Aether Archives — Geheimakte 115** é um projeto não oficial criado para estudo, desenvolvimento web e apresentação de portfólio.

Call of Duty, Black Ops, Zombies e os demais nomes, personagens, locais, imagens e elementos associados ao jogo pertencem aos respectivos detentores de direitos. Este projeto não possui afiliação, patrocínio ou aprovação oficial da Activision ou da Treyarch.

As referências visuais preservadas dentro do projeto são usadas apenas para demonstrar a interface e manter fidelidade ao material de origem no contexto educacional e de portfólio.
